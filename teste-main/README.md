# Clínica Digital

Você é um estrategista de marketing digital + diretor de arte especializado em landing pages de alta conversão para prestadores de serviço criativo (B2B). Vamos criar uma landing page de portfólio para um(a) DESIGNER/AGÊNCIA DE WEB DESIGN especializado em sites para clínicas odontológicas. IMPORTANTE: esta página NÃO é o site de uma clínica. É a página do PRESTADOR DE SERVIÇO, cujo cliente-alvo são dentistas e clínicas odontológicas que precisam de um site novo ou de reposicionamento digital. Objetivo da página: gerar leads qualificados (dentistas interessados) que preencham um formulário, chamem no WhatsApp ou agendem uma call — provando, através de cases reais e copy estratégico, que este profissional entende o nicho odontológico melhor que qualquer agência genérica. Tom de voz: especialista, direto, confiante — fala a língua do dono de clínica (que pensa em agenda cheia, autoridade e faturamento, não em "design bonito").

Antes de desenhar, defina com clareza: 1. NICHO DECLARADO: "Web design especializado para dentistas e clínicas odontológicas" — nunca "faço sites para qualquer segmento". Especialização = autoridade = preço maior. 2. PROMESSA CENTRAL (transformação, não entrega): Não venda "site bonito e responsivo". Venda o resultado de negócio: "Um site que faz o telefone/WhatsApp da sua clínica tocar com pacientes qualificados, não só visitas." 3. OFERTA CLARA (o que exatamente a pessoa recebe): - Nome do pacote/serviço (ex: "Site Odonto Pro", "Presença Digital para Clínicas") - O que está incluído: design, copy, SEO local, integração WhatsApp, otimização mobile, prazo de entrega - Diferencial de nicho: já entende de linguagem odontológica, antes/depois, compliance de propaganda em saúde (CFO/CRO), gatilhos que funcionam para esse público 4. PROVA DE NICHO (o que te credencia especificamente em odontologia): - Nº de clínicas atendidas - Resultados mensuráveis (ex: "aumento de 40% em agendamentos via site") - Depoimentos de dentistas reais - Prints/mockups de projetos entregues 5. CTA ÚNICO: escolha 1 ação (ex: "Quero um site assim para minha clínica" → WhatsApp ou formulário de diagnóstico gratuito) e repita em todo o site. 6. GATILHO DE URGÊNCIA/ESCASSEZ (se aplicável e honesto): "Atendo apenas X clínicas por mês para garantir qualidade" ou "Vagas limitadas para novos projetos em [mês]"

# Odonto Websites - Landing Page de Alta Conversão

Landing page de portfólio para web designer / agência especializada em sites para clínicas odontológicas.

## 🚀 Como rodar localmente (Localhost)

### Pré-requisitos
- Node.js (v18+) ou Bun
- npm ou bun

### Instalação e Execução

Usando npm:
```bash
npm install
npm run dev
```

Ou usando Bun:
```bash
bun install
bun run dev
```

A aplicação estará disponível em `http://localhost:3000`.

## 📦 Scripts disponíveis
- `npm run dev`: Inicia o servidor de desenvolvimento
- `npm run build`: Cria a build de produção
- `npm run preview`: Visualiza a build de produção localmente
- `npm run lint`: Executa a verificação de linter
